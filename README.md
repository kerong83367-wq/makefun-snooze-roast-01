A roast of the alarm clock that rings at 6 AM on a Saturday: "My alarm clock
has exactly one job, and on Saturday at 6 AM it does it with the enthusiasm
of someone who has never been loved." The program writes it to
`/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
